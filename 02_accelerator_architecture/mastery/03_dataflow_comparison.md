# 03_dataflow_comparison.md: Mastering WS, OS, and IS Dataflows

이 문서는 AI 가속기 설계의 핵심인 세 가지 데이터플로우(Weight Stationary, Output Stationary, Input Stationary)의 특성을 비교하고, 각 방식이 메모리 대역폭과 연산 효율에 미치는 영향을 검증합니다. 시스톨릭 어레이 아키텍처에서 데이터 재사용 전략이 하드웨어 성능에 어떤 차이를 만드는지 이해하는 것을 목표로 합니다.

## 📝 개념 확인 문제 (Quiz)

### 문제 1. Stationary 방식을 사용하는 가장 중요한 이유

* **질문:** Weight Stationary (WS), Output Stationary (OS), Input Stationary (IS)를 사용하는 가장 중요한 이유는 무엇인가?
* **정답: C. 데이터 재사용을 극대화하여 메모리 접근량을 줄이기 위해**
* **해설:** AI 연산에서 가장 비용이 큰 작업은 DRAM 접근입니다. 특정 데이터를 PE 내부에 고정(Stationary)하여 재사용함으로써 외부 메모리 통신량을 최소화하는 것이 핵심 목적입니다.

### 문제 2. Weight Stationary 방식의 고정 데이터

* **질문:** Weight Stationary 방식에서 PE 내부에 고정되어 있는 데이터는 무엇인가?
* **정답: B. 가중치 행렬 B**
* **해설:** 가중치(Weight)를 PE의 레지스터에 고정하고 입력 데이터와 부분합을 흐르게 하여, 가중치를 메모리에서 다시 읽어오는 비용을 절감합니다.

### 문제 3. Output Stationary 방식의 유지 데이터

* **질문:** Output Stationary 방식에서 PE 내부에 유지되는 값은 무엇인가?
* **정답: C. 출력 partial sum**
* **해설:** 계산 중인 부분합(Partial Sum)을 PE 내부 누산기(Accumulator)에 고정하여, 최종 결과가 완성될 때까지 중간 결과를 DRAM에 쓰고 다시 읽는 과정을 생략합니다.

### 문제 4. Input Stationary 방식의 고정 데이터

* **질문:** Input Stationary 방식에서 PE 내부에 고정되는 데이터는 무엇인가?
* **정답: A. 입력 A**
* **해설:** 입력 행렬 A의 요소를 PE에 고정하고 가중치와 부분합을 이동시키며 연산합니다. 입력 데이터의 재사용률이 극도로 높을 때 유리합니다.

### 문제 5. 데이터플로우 방식 간의 관계

* **질문:** WS, OS, IS에 대해 올바른 설명은 무엇인가?
* **정답: C. 모든 방식은 동일한 결과를 만들지만 메모리 접근 패턴이 다르다.**
* **해설:** 세 방식 모두 수학적으로는 동일한 행렬 곱셈 결과를 도출합니다. 다만 하드웨어에서 어떤 데이터를 고정하느냐에 따라 DRAM 트래픽과 에너지 소비 효율이 달라집니다.

### 문제 6. 특정 연산 조건(M=1, K=4096, N=4096)에 최적인 방식

* **질문:** $M = 1, K = 4096, N = 4096$ 연산에 가장 적합한 데이터플로우는 무엇인가?
* **정답: C. IS**
* **해설:** 행렬 A가 벡터($M=1$)인 경우, 이 입력 벡터 하나가 모든 출력 뉴런 계산에 반복적으로 사용됩니다. 따라서 입력을 PE에 고정하는 Input Stationary 방식이 데이터 재사용 측면에서 가장 유리합니다.

### 문제 7. 대규모 FC 레이어 추론 시 유리한 방식

* **질문:** 배치 크기가 크고 동일한 가중치를 반복 사용하는 Fully Connected Layer 추론에서 일반적으로 유리한 데이터플로우는 무엇인가?
* **정답: A. WS**
* **해설:** 여러 입력 배치에 대해 동일한 가중치 행렬을 적용해야 하므로, 가중치를 PE에 고정해두고 입력을 흘려보내는 Weight Stationary 방식이 효율적입니다.

### 문제 8. Output Stationary의 주요 장점

* **질문:** Output Stationary의 주요 장점은 무엇인가?
* **정답: A. 출력 partial sum을 DRAM에 반복 저장하지 않는다.**
* **해설:** 중간 연산 결과인 부분합을 외부 메모리로 내보내지 않고 내부에서 완결 짓기 때문에, 출력 관련 메모리 대역폭 소모를 크게 줄일 수 있습니다.

### 문제 9. AI 가속기의 최대 비용 작업

* **질문:** AI 가속기에서 일반적으로 가장 비용이 큰 작업은 무엇인가?
* **정답: C. DRAM 접근**
* **해설:** 온칩(On-chip) 연산이나 레지스터 접근에 비해 외부 DRAM에서 데이터를 읽고 쓰는 작업은 수십에서 수백 배 더 많은 에너지를 소모합니다.

### 문제 10. 데이터플로우 비교 분석의 목적

* **질문:** stationary를 비교 분석한 코드의 주된 목적은 무엇인가?
* **정답: C. 데이터플로우별 메모리 접근량과 실행 비용을 비교하기 위해**
* **해설:** 알고리즘의 수치적 정확도보다는 하드웨어 관점에서 어떤 매핑 방식이 주어진 워크로드에 대해 가장 적은 통신 비용을 유발하는지 정량적으로 분석하는 것이 목적입니다.

### 문제 11. Large Balanced MatMul에서의 DRAM 트래픽

* **질문:** 대규모 균형 행렬 곱셈($M=N=K=4096$)에서 DRAM 트래픽이 가장 적은 데이터플로우는 무엇인가?
* **정답: B. WS와 IS**
* **해설:** 모든 차원이 균일하게 큰 경우, 입력(IS)이나 가중치(WS)를 고정하는 것이 부분합(OS)을 고정하는 것보다 전체적인 메모리 대역폭 사용량 측면에서 더 효율적인 경우가 많습니다.

## 💡 참고 사항 (Notes)

### 1. 가속기 설계의 정수 (Hardware Insight)

데이터플로우의 선택은 고정된 하드웨어 자원 내에서 '누구를 머물게 하고 누구를 흐르게 할 것인가'를 결정하는 전략적 선택입니다. 본 퀴즈에서 다룬 원리는 특정 알고리즘에 최적화된 도메인 특화 가속기(DSA)를 설계할 때 메모리 계층 구조(Memory Hierarchy)와 인터커넥트(Interconnect)를 설계하는 근간이 됩니다.
