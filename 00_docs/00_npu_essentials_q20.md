# 00_npu_essentials_q20.md: AI Hardware Core Concepts

이 문서는 AI 반도체 및 NPU 설계의 핵심 개념 20가지를 정리한 요약본입니다. **analysis** 와 **mastery** 단계의 학습을 돕기 위한 퀵 레퍼런스 가이드로 활용됩니다.

---

## Section 1: 기초 구조 및 메모리 계층 (Q1 ~ Q5)

| 번호 | 질문 (Question) | 정답 및 핵심 해설 (Key Concept) |
| :--- | :--- | :--- |
| **Q1** | **SIMD**의 약자는? | **Single Instruction Multiple Data**. 하나의 명령어로 여러 데이터를 동시 처리하는 병렬 방식입니다. |
| **Q2** | **4 KB** 데이터 접근 시 가장 빠른 곳은? | **L1 캐시**. 프로세서 코어와 가장 가까워 지연 시간이 최소화된 영역입니다. |
| **Q3** | 일반적으로 가장 느린 접근은? | **HDD 파일 읽기**. 기계식 방식으로 반도체 기반 메모리보다 수천 배 느립니다. |
| **Q4** | **NumPy**가 Python Loop보다 빠른 이유는? | 내부적으로 **C 기반 벡터화 연산**을 수행하기 때문입니다. |
| **Q5** | **Arithmetic Intensity**가 낮을 때의 병목은? | **메모리 대역폭**. 연산량보다 데이터 이동량이 많아 발생하는 정체입니다. |

## Section 2: 하드웨어 가속 및 효율 (Q6 ~ Q10)

| 번호 | 질문 (Question) | 정답 및 핵심 해설 (Key Concept) |
| :--- | :--- | :--- |
| **Q6** | 행렬곱의 표준 영문 약어는? | **MatMul**. 딥러닝 연산의 핵심 단위를 지칭하는 표준 명칭입니다. |
| **Q7** | **Systolic Array**의 핵심 아이디어는? | 격자 모양의 PE들이 데이터를 일정한 박자로 흘려보내며 연산하는 구조입니다. |
| **Q8** | **LLM 추론**에 가장 효과적인 Dataflow는? | **Weight Stationary**. 가중치를 PE에 고정하여 데이터 이동 에너지를 절약합니다. |
| **Q9** | 가장 효율적인 AI 추론 장치는? | **NPU**. AI 연산에만 특화된 구조로 단위 전력당 처리량이 가장 압도적입니다. |
| **Q10** | **Peak TFLOPS**가 높으면 항상 더 빠른가? | **아니오**. 실제 속도는 메모리 대역폭과 활용률(Utilization)에 의해 결정됩니다. |

## Section 3: 아키텍처 및 수치 연산 (Q11 ~ Q15)

| 번호 | 질문 (Question) | 정답 및 핵심 해설 (Key Concept) |
| :--- | :--- | :--- |
| **Q11** | **NPU**의 N은 무엇의 약자인가? | **Neural**. 신경망 모사 연산을 가속하기 위한 장치임을 의미합니다. |
| **Q12** | **INT8** 누적 시 적절한 Accumulator 비트는? | **INT32**. 오버플로우와 정밀도 손실을 방지하기 위해 충분히 크게 설정합니다. |
| **Q13** | **Verilog RTL** 시뮬레이션의 특징은? | 실제 하드웨어의 클럭 단위 타이밍과 동작에 더 가깝게 모사합니다. |
| **Q14** | **INT8** 연산 결과가 비정상적 음수라면 원인은? | **오버플로우**. 표현 범위(-128~127)를 넘어 부호 비트가 반전된 결과입니다. |
| **Q15** | **PE Array**를 4배 늘리면 나타나는 변화는? | 처리량이 4배 증가하며 이론상 **지연 시간이 약 1/4로 감소**합니다. |

## Section 4: 성능 지표 및 스케일링 (Q16 ~ Q20)

| 번호 | 질문 (Question) | 정답 및 핵심 해설 (Key Concept) |
| :--- | :--- | :--- |
| **Q16** | **Latency**의 가장 적절한 정의는? | 한 작업이 시작되어 완료되기까지 걸리는 **시간적 지연**입니다. |
| **Q17** | **Latency**와 **Throughput**의 관계는? | **대립 관계(Trade-off)**. 한쪽을 극대화하면 다른 쪽이 희생되기 쉽습니다. |
| **Q18** | **자율주행 인지 시스템**에 중요한 지표는? | **p99 Latency**. 최악의 지연 상황에서도 안전을 보장하기 위한 수치입니다. |
| **Q19** | **전력 제한 기기**에서 가장 중요한 지표는? | **단위 전력당 처리량 (TOPS/W)**. 모바일 환경의 핵심인 전성비 지표입니다. |
| **Q20** | 단순 자원 확장에 따른 성능 향상의 의미는? | **Scaling**. 자원 확장이며 면적이나 전력 비용이 수반된 결과일 수 있습니다. |
